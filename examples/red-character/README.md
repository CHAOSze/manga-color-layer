# 角色动画分层

每只眼拆为眼白底、眼球（虹膜＋瞳孔＋高光）、眉眼框三层，共14层。左右按画面方向命名。嘴部、脸底、头发、躯干及手袖也按运动需要分层。眼球保留原图颜色与细节，云端补画仅用于原眼球下方眼白。

图层顺序为眼白在下、眼球居中、眉眼框在上。眉眼框的眼睛开口控制可见范围，避免轻微眼球移动压过眼睑。每只眼的三层跟随 EYE_L_CTRL / EYE_R_CTRL，再跟随 HEAD_CTRL；眼球可单独调整位置。眼球以 iris 命名；sclera 为眼白；frame 为眉眼框。

已检查：初始合成对照、隐藏眼球后的眼白、两个眼球独立图层，以及上下左右极端位置。预览测试为水平±4px、垂直±2px，40帧局部运动；不是实际 AE 测试。此版没有增加眨眼、独立眼睑变形或口型绑定。更大幅度视线运动需要重新检查眼白范围和遮挡。

运行 import-to-ae.jsx 可导入PNG并组织控制器；也可将 character-layers.psd 作为合成导入。导入脚本不自动生成木偶网格或动画关键帧。reviews/gaze-preview.gif 是视线变化预览，reviews/eye-layer-review.jpg 是分层对照，reviews/gaze-directions.jpg 是四方向检查。
