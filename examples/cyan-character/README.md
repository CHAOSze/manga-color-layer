# 青发角色图 1：分层示例

仅包含回头俯视的图 1，共 11 层：后发、干净头脸颈部、左右眼各自的眼白/虹膜/眼睑遮挡、肩部上臂、前发，以及衣袖褶皱。左右按画面方向命名。

脸下圆弧为肩部，再下方为衣袖；肩部与衣袖接触处保持约束，发根固定，只做小幅发梢形变。每只眼的白底、虹膜和眼睑独立，保留已确认的青蓝虹膜着色。

- [全部 11 层](panel-01/previews/all-layers.jpg)。
- [本地小幅运动预览](panel-01/reviews/motion-preview.gif)。

panel-01/colored-character.png 是分层后静态组合，不是上色中间结果。PNG 为统一画布的部件，不是动画帧序列。

在 AE 中运行 panel-01/import-to-ae.jsx 导入 PNG 与控制器，或以合成方式导入 PSD。导入脚本不自动创建木偶网格与关键帧。

历史检查包括 PSD 重新读取、独立图层和本地小范围头发/头部/衣袖/视线运动。预览不是 AE 实测。原工作尺寸下头部约 2 像素、发梢约 5 像素、衣袖内部约 2 像素；视线约水平 ±2、垂直 ±1 像素。扩大动作范围须重新检查。没有完整眨眼或口型系统。

此次发布仅整理已有成果，没有重新生成素材或运行 AE 绑定。被遮挡部分为推断补画；工作补画分辨率约 1K，保留原画布不代表所有内容均原生高分辨率绘制。详见 panel-01/reviews/validation.json。
